# ✂️ Glamorous Salon | Booking & Management System

**Glamorous Salon** is a full-stack salon booking and management web application designed for both customers and salon administrators. 

It provides an elegant interface for customers to explore services and book appointments, while offering a powerful dashboard for administrators to manage the business.

---

## 🌐 Live Links

- **Live Application:** [https://glamorous-salon-1vws.onrender.com/](https://glamorous-salon-1vws.onrender.com/) *(Note: The live server may take 30-50 seconds to wake up on the first load due to free-tier hosting).*

---

## ✨ Features Implemented

- **User Authentication:** Secure JWT-based login and registration system.
- **Password Recovery:** Email OTP system for resetting forgotten passwords.
- **Service Booking:** Customers can easily browse services and schedule appointments.
- **Admin Dashboard:** Comprehensive control panel to manage users, bookings, and salon services.
- **Dynamic Services Gallery:** Integrated image handling for showcasing salon experiences.
- **Database Persistence:** Reliable data storage using SQLite.

---

## 🏗️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
- **Backend:** Node.js, Express.js
- **Database:** SQLite
- **Authentication:** JWT, Bcryptjs
- **Email Service:** Nodemailer (SMTP)
- **Deployment:** Render
